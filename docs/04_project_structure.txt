PROJECT STRUCTURE

README.md                     General description and instructions (in the root).
claude-usage-summary.md       AI use (already written).
requirements.txt              Python dependencies.
.github/workflows/static.yml  Publishes web/ on GitHub Pages (push to v2).

web/                          Static website:
  index.html, style.css       Structure and styles (dark "orbital night" theme).
  app.js                      Core: data loading, calendar, charts.
  map.js                      Map (Leaflet, Esri, GIBS layer).
  extras.js                   Countries, fires, daily stripes.
  ui.js                       Landing page, tabs, voice assistant.
  vendor/                     Local Leaflet and Leaflet.Draw.
  data/                       JSON/CSV generated by the pipeline (~20 MB).
docs/                         This documentation.

GIT BRANCHES: main, deploy-web-pages, fix-pages-artifact-deployment, v2, v3 (most recent).
